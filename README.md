## Descripción
Taller de arreglos unidimensionales, matrices y ArrayList en Java.
Los datos se generan aleatoriamente y se aplican principios de Clean Code, DRY, KISS y SOLID.

## Instrucciones de ejecución
Opción 1 — Ejecutar con Visual Studio Code 

### Paso 1: Instala la extensión de Java
1. Abre VS Code.
2. Ve a la pestaña **Extensiones** (`Ctrl + Shift + X`).
3. Busca **"Extension Pack for Java"** (de Microsoft).
4. Haz clic en **Install**.

### Paso 2: Abre el proyecto
1. En VS Code, ve a **File → Open Folder...**
2. Selecciona la carpeta **`Taller-Estructuras-Lineales`**.
3. Espera unos segundos mientras la extensión carga el proyecto.

### Paso 3: Ejecuta cualquier ejercicio
1. En el panel izquierdo, despliega `src` y  elige el paquete (`arreglos`, `arraylist` o `matrices`).
2. Haz clic en el archivo `.java` que quieras ejecutar.
3. Verás un **(Run)** en la esquina superior derecha del editor.
4. Haz clic en él (o presiona `Ctrl + F5`).
5. La salida aparecerá en la pestaña **Terminal** en la parte inferior.
